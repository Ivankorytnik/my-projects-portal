# TestDrive Doc Desktop

Отдельная Windows-версия TestDrive_Doc для установки на ноутбук.

## Что это

- обычное Windows-приложение, а не сайт;
- запускается в отдельном окне;
- формы, ПДн, фото и формирование документов обрабатываются локально;
- штатные DOCX-шаблоны входят в сборку;
- для ежедневной работы интернет не требуется;
- веб-версия `/testdrive/` остаётся отдельной и не изменяется.

## Сборки

GitHub Actions формирует два варианта:

1. `TestDrive-Doc-...exe` — установщик Windows;
2. portable EXE — запуск без установки.

## Локальный запуск разработчика

```bash
npm install
npm start
```

## Сборка Windows

```bash
npm install
npm run dist
```

Сборка запускается автоматически при изменениях desktop-версии.
