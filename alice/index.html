Voice AI / Personal Assistant

Алиса AI

Голосовой вход в персонального AI-ассистента через Яндекс Алису. Пользователь говорит Алисе, запрос проходит через Supabase и OpenAI, а ответ возвращается голосом.

Проектирование MVP
«Алиса, запусти Иван AI»

После запуска навыка можно задавать вопросы о проектах, задачах, письмах и личной базе знаний.

Архитектура
1

Яндекс Алиса

Распознает голос и передает текст пользовательской реплики навыку.

2

Webhook

HTTPS endpoint навыка принимает запрос и нормализует данные диалога.

3

Supabase

Edge Function хранит серверную логику, память и безопасный доступ к ключам.

4

OpenAI

Формирует ответ с учетом контекста и возвращает его Алисе для озвучивания.

Что должен уметь MVP

  • Принимать голосовые запросы через Алису.
  • Поддерживать короткий контекст текущего диалога.
  • Обращаться к OpenAI через серверную функцию.
  • Возвращать короткий разговорный ответ для озвучивания.
  • Позже подключить память Korytnik Hub и персональные данные из Supabase.

Компоненты

  • Навык в Яндекс Диалогах.
  • Webhook alice-chatgpt.
  • Supabase Edge Function.
  • Secret OPENAI_API_KEY.
  • Таблица памяти диалогов на следующем этапе.
Roadmap
Этап 1
Навык и webhookСоздать навык «Иван AI» и подключить HTTPS endpoint Supabase.
Этап 2
Ответы OpenAIДобавить серверный запрос к модели, обработку ошибок и лимит длины ответа.
Этап 3
ПамятьХранить диалоги и профиль ассистента в Supabase, чтобы ответы учитывали прошлый контекст.
Этап 4
Интеграция с HubПодключить проекты, задачи и другие разрешенные данные Korytnik Hub.
Важно: ключ OpenAI нельзя размещать в коде страницы или навыка. Он должен храниться только в Supabase Secrets и использоваться внутри Edge Function.
