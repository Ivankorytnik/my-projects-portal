# Фото на почту v1.0.0

Android MVP для сценария «сфотографировал → фотография автоматически ушла на выбранную почту».

## Возможности
- список сохраненных получателей;
- последний получатель запоминается;
- добавление и удаление адресов;
- запуск системной камеры;
- автоматическая SMTP-отправка сразу после подтверждения кадра;
- копия снимка остается в `Pictures/PhotoMail`;
- почта отправителя настраивается один раз;
- пароль приложения шифруется ключом Android Keystore;
- резервное копирование данных приложения отключено.

## Поддерживаемая схема SMTP
Версия 1.0.0 использует защищенный SMTPS на порту 465. Примеры:
- Gmail: `smtp.gmail.com:465`
- Яндекс: `smtp.yandex.ru:465`
- Mail.ru: `smtp.mail.ru:465`

Используйте отдельный пароль приложения, не основной пароль аккаунта.

## Android
- минимум Android 10 / API 29;
- compile / target SDK 35;
- package: `pro.korytnikhub.photomail`.
