Secure TD Docs

MVP для подготовки и печати комплекта документов из одной карточки клиента. Рабочий контур специально оставлен локальным, чтобы персональные данные не передавались через публичный сайт.

● MVP v0.1 · локальный режим
Один ввод данныхПовторяющиеся поля заполняются один раз и используются в комплекте документов.
Печать комплектаПредпросмотр и печать отдельных документов или всего комплекта.
Без облачной базы ПДнКлиентские данные не должны сохраняться в GitHub, Supabase или публичном хранилище.
АвтоочисткаРабочая локальная версия предусматривает блокировку сессии и очистку введённых данных.
Защищённый режимНа этой публичной странице нет формы ввода персональных данных и нет рабочих шаблонов. Запуск рабочего MVP выполняется только из локального пакета на доверенном компьютере.
