TestDrive_Doc

Локальный MVP для подготовки документов краткосрочного тест-драйва из одной карточки клиента. Обработка персональных данных выполняется на доверенном компьютере.

● MVP v0.2.6 · локальный режим

Настоящие DOCXТри файла формируются непосредственно из исходных Word-шаблонов с сохранением их структуры и оформления.
Папка храненияМожно выбрать локальную папку. Для каждого участника создаётся отдельная папка «ФИО + дата» с тремя документами.
Один ввод данныхФИО, паспорт, водительское удостоверение, автомобиль и менеджер вводятся один раз и подставляются в комплект.
Без облачной базы ПДнДанные участников тест-драйва не сохраняются приложением в GitHub, Supabase или публичной базе.
Локальная защитаPIN текущей сессии, автоблокировка, автоочистка и отсутствие истории клиентов внутри приложения.
Несколько участниковВ одной сессии можно оформить несколько клиентов подряд, сохраняя каждого в отдельную папку.
Защищённый режимРабочая форма с паспортными данными не размещена на сайте. После запуска приложение работает локально.
