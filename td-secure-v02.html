Secure TD Docs

Локальный MVP для подготовки документов краткосрочного тест-драйва из одной карточки клиента. Публичный сайт содержит только карточку проекта, а обработка персональных данных выполняется на доверенном компьютере.

● MVP v0.2 · локальный режим
Настоящие DOCXТри файла формируются непосредственно из исходных Word-шаблонов с сохранением их структуры и оформления.
PDF и печатьЛокальная конвертация через установленный Microsoft Word или LibreOffice, без отправки документов в онлайн-сервисы.
Один ввод данныхФИО, паспорт, водительское удостоверение, автомобиль и менеджер вводятся один раз и подставляются в комплект.
Без облачной базы ПДнКлиентские данные не сохраняются в GitHub, Supabase или публичном хранилище.
Локальная защитаPIN текущей сессии, автоблокировка, автоочистка и отсутствие истории клиентов внутри приложения.
Комплект ZIPПо одной команде формируются три DOCX и, при доступном локальном конвертере, три PDF.
Защищённый режимНа этой публичной странице нет формы ввода ПДн, VIN-базы и рабочих Word-шаблонов. Полный пакет v0.2 не публикуется в открытом репозитории.
