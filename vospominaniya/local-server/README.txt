ВОСПОМИНАНИЯ: ЛОКАЛЬНОЕ РАСПОЗНАВАНИЕ

Что это
Небольшой сервер на вашем компьютере. Страница korytnikhub.pro/vospominaniya/ отправляет ему
аудио главы, он распознаёт речь (Whisper) и литературно оформляет текст (Ollama).
Всё работает на компьютере, бесплатно, запись никуда в интернет не уходит.
Сервер слушает только адрес 127.0.0.1:8790, с других устройств он недоступен.

Установка
1. Распакуйте папку в любое место.
2. Запустите install.bat. Он:
   - найдёт Python (или поставит Python 3.12 через winget);
   - создаст отдельное окружение в %LOCALAPPDATA%\VospominaniyaLocal и поставит faster-whisper;
   - возьмёт уже скачанную модель Whisper large-v3-turbo, если она есть (например, от Таньки Ассистента);
   - выберет модель Ollama: qwen2.5:7b, если она есть, иначе qwen2.5:3b;
   - попросит задать пароль для страницы (можно прежний);
   - сделает ярлык «Воспоминания - локальный сервер» на рабочем столе и в автозагрузке;
   - запустит сервер и проверит его.

Работа
- На странице «Воспоминания» на экране входа выберите «на этом компьютере, бесплатно».
- Chrome может спросить разрешение на доступ к устройствам в локальной сети. Разрешите.
- Первое распознавание дольше обычного: модель загружается в память.
- Проверить, что сервер жив: откройте http://127.0.0.1:8790/health

Полезное
- Сменить пароль: set-password.bat
- Журнал: %LOCALAPPDATA%\VospominaniyaLocal\server.log
- Настройки: %LOCALAPPDATA%\VospominaniyaLocal\config.json
  (модель Whisper, модель Ollama, порт; пароль хранится только в виде хеша)
- Удалить: uninstall.bat. Главы на сайте не трогаются, они хранятся в браузере.
- Вернуться к облаку: на экране входа выберите «в облаке, как раньше».

Ограничения
- Работает только на компьютере, где запущен сервер. На телефоне выбирайте облако
  или распознавайте позже на компьютере.
- Качество литературной обработки зависит от модели Ollama. qwen2.5:3b заметно слабее
  облачной модели, qwen2.5:7b лучше, но медленнее и требует около 8 ГБ памяти.
  Сменить: ollama pull qwen2.5:7b, затем снова install.bat.
